# First-Group | GitHub-standaarden

Deze repository bevat ons openbare organisatieprofiel en de standaardformats voor projecten binnen First-Group.

| Onderdeel | Doel |
| :--- | :--- |
| [Organisatieprofiel](profile/README.md) | De openbare introductie van First-Group |
| [Foutmelding](.github/ISSUE_TEMPLATE/bug_report.md) | Een probleem duidelijk beschrijven en reproduceerbaar maken |
| [Idee of verbetering](.github/ISSUE_TEMPLATE/feature_request.md) | Het gewenste resultaat en acceptatiecriteria vastleggen |
| [Wijzigingsvoorstel](.github/PULL_REQUEST_TEMPLATE.md) | Uitleggen wat verandert en hoe het is gecontroleerd |

GitHub gebruikt de standaardformats voor projecten zonder eigen formats. Een project kan altijd zijn eigen invulling gebruiken.

## Nieuwe projecten

Gebruik de interne projecttemplate om doel, eigenaar, installatie en beheer vanaf het begin vast te leggen. De interne startpagina is beschikbaar via de ledenweergave van het organisatieprofiel.
